
# 💧 Controle de Níveis de Água

Projeto desenvolvido em Python para simular o monitoramento dos níveis de água de um reservatório, utilizando cores para identificar cada situação.

## 🎯 Objetivo

Exibir mensagens coloridas no terminal de acordo com o nível de água, facilitando a identificação de situações críticas e níveis elevados.

## 🛠️ Tecnologias utilizadas

- Python
- Biblioteca Colorama

## 📊 Níveis do reservatório

| Nível | Situação | Cor |
|---|---|---|
| 1 | Muito baixo (crítico) | Vermelho |
| 2 | Baixo | Amarelo |
| 3 | Médio | Verde |
| 4 | Alto | Ciano |
| 5 | Muito alto (alerta) | Azul |

## ▶️ Como executar

1. Instale o Python.
2. Instale as dependências com `pip install -r requirements.txt`.
3. Execute o programa com `python main.py`.
